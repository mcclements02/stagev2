The Connected Sprawl

Zarri's 15-mile founder hustle: a GTA-style open world with a startup economy, built in Unreal Engine 5. Drive the city, run the gigs, build the company.

Download for Mac

A self-contained build for Apple silicon Macs on macOS 14 or later, about 4.3 GB. Nothing to install beyond the app itself: no engine, no developer tools.

How to get it

The disk image comes in three parts because of GitHub's file-size limit. Download all three and the checksum file into one folder, then join them with one command in Terminal:

cat ConnectedSprawl-0.231.2.dmg.part-* > ConnectedSprawl-0.231.2.dmg
shasum -a 256 -c ConnectedSprawl-0.231.2.dmg.sha256

Open the DMG and drag ConnectedSprawl to Applications.

Under the hood

What this build is

Engine

Unreal Engine 5.8

A procedurally built city: streets, kerbs, driveways, buildings and interiors are generated from a design catalogue, with the Junction district hand-tuned against reference photography.

Requirements

Apple silicon, macOS 14+

Built for arm64 only. Expect a 2 to 3 minute first load while the city builds; later loads are faster. A controller or keyboard: W, A, S, D to drive, E to exit the car.

Version

0.231.2, Development build

The HUD prints connectedsprawl ver. 0.231.2; quote it in a bug report. Later versions appear under All releases above.
